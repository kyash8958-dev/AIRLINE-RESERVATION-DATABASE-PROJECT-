# AIRLINE-RESERVATION-DATABASE-PROJECT-
✈️ Airline Reservation Database Project

📌 Project Overview

This project is an Airline Reservation Database Management System developed using MySQL.

The main purpose of this project is to manage airline-related information such as passengers, flights, bookings, seats, tickets, and payments in a structured database.

🛠️ Technologies Used

* MySQL 8+
* SQL
* Relational Database Management System (RDBMS)

📂 Database Features

The database includes functionality for:

* Passenger management
* Airline and flight management
* Airport information
* Flight schedules
* Seat management
* Ticket booking
* Payment records
* Booking details
* Relationships between different tables
* Views for ticket information
* Triggers for automatic seat booking operations

🗃️ Main Database Components

The project contains:

* Tables – Store airline, passenger, flight, booking and payment data.
* Primary Keys – Uniquely identify records.
* Foreign Keys – Maintain relationships between tables.
* Views – Provide useful combined information.
* Triggers – Automate database operations such as seat booking.

🚀 How to Run the Project

1. Install MySQL 8+.
2. Open MySQL Workbench or another MySQL-compatible SQL editor.
3. Open the project SQL file.
4. Run the complete SQL script.
5. The database airline_reservation will be created automatically.
6. Execute the queries to view and manage the data.

📊 Example Operations

The project can be used to perform operations such as:

* Add passengers
* Add flights
* Create bookings
* Assign seats
* Store payment information
* View ticket details
* Check flight information
* Manage reservation records

🎯 Project Objective

The objective of this project is to demonstrate practical knowledge of:

* SQL queries

* Normalization
* Primary and foreign keys
* Joins
* Views
* Triggers
* Relational database concepts
